# Turbo.az Vehicle Market Analysis

This project is an end-to-end data science study focused on the Azerbaijani automotive market. It includes data collection from **Turbo.az**, cleaning, and visualization to understand market trends.

## 🚀 Overview
The main goal of this project is to analyze car listings to uncover insights such as:
* **Price Distribution:** How do brands and production years affect pricing?
* **Feature Correlation:** The relationship between mileage, engine size, and market value.
* **Data Transformation:** Converting raw, messy text data into structured numerical formats.

## 🛠 Tech Stack
* **Python** (Pandas, NumPy)
* **Web Scraping** (BeautifulSoup)
* **Data Visualization** (Matplotlib, Seaborn)
* **Environment:** Jupyter Notebook

## 📊 Key Features
1. **Web Scraping:** Automated extraction of vehicle data.
2. **Data Cleaning:** Using Regex to handle currency, mileage, and engine specifications.
3. **Exploratory Data Analysis (EDA):** Insights into market supply and pricing trends.

## 📁 Project Structure
- `main.ipynb`: The primary notebook containing the scraping and analysis code.
- `README.md`: Project documentation.

## 💡 Usage
1. Clone the repository.
2. Open `main.ipynb` in Jupyter Notebook.
3. Run the cells to see the analysis and visualizations.
